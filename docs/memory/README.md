# 项目记忆（Memory）说明

本目录是**团队可审查、随仓库版本化**的项目知识库，配合 VS Code Copilot 的三层记忆模型使用。

## 三层记忆模型

| 层 | 位置 | 生命周期 | 用途 |
|----|------|---------|------|
| **项目说明（始终加载）** | `.github/copilot-instructions.md` + `AGENTS.md` | 随仓库，始终注入 | 铁律、协作协议、指向其余文档的入口 |
| **项目知识库（按需读取）** | `docs/memory/*.md` | 随仓库，按需加载 | 架构、领域概念、跨服务约定等稳定事实 |
| **本地 memory 工具（会话/仓库）** | VS Code 本地 `/memories/`（不入库） | 个人/会话级 | 个人偏好、临时任务上下文、未定稿的新知识 |

## 各文件职责

- `README.md`（本文件）：说明记忆分层与维护规则。
- `project-overview.md`：项目是什么、包含哪些服务、技术栈基线、目录地图。
- `architecture.md`：服务拓扑、端口、数据流、鉴权模型、部署形态。

## 维护规则

1. **稳定事实进知识库**：架构决策、服务职责、端口、命名约定等**经过评审**的内容写进本目录，随 PR 合入。
2. **决策进 ADR**：有取舍的架构决策写 `docs/decisions/ADR-xxx.md`，本目录只放结论性的"现状"。
3. **未定稿的知识进本地 memory**：Agent 在会话中沉淀的新知识先写本地 memory；稳定且对团队有用后，提炼进 `docs/memory/` 并走正常评审。
4. **避免陈旧**：代码变更后，相关 `docs/memory/` 描述须同步更新，防止 AI 读到过时信息。

> 提示：VS Code 中可用 **Chat: Show Memory Files** 查看本地 memory 文件；AI 也可通过 memory 工具在会话间保存/读取用户偏好与仓库知识。
