# 交接单模板

> 开发 → 测试、测试 → 审查时创建，保存为 `docs/handoffs/Hxxx-Txxx-从-到.md`。

```markdown
# 交接单：Txxx <任务标题>

- 日期: 2026-10-25
- 从: developer  →  到: tester
- 分支: feat/Txxx-短描述
- 任务卡: docs/tasks/Txxx-*.md
- 相关测试报告/审查报告: （如有，填路径）

## 本次交付内容
- 变更文件/模块清单（相对路径）
- 新增/变更的 API（对应契约文件）
- 数据库迁移：有/无（脚本路径）
- 新增环境变量：有/无（已更新 .env.example：是/否）

## 自检结果
- lint/type-check: ✅/❌（命令与结果摘要）
- 现有测试: ✅ 全部通过 / ❌（说明）
- 本地手动验证: （做了什么）

## 测试建议（developer→tester）
- 重点验证：
- 已知薄弱点/未覆盖场景：

## 发现的问题（本次未修，待调度者决策）
- 问题 1（影响范围、建议开新卡）

## 备注
（返工交接时写明：针对哪条审查/缺陷意见做了什么修改）
```
